## 📖 Overview

AI Business Copilot is a comprehensive AI-driven analytics platform designed to help businesses make smarter, data-driven decisions.

The platform combines Business Intelligence, Machine Learning, AI-powered insights, forecasting, executive reporting, anomaly detection, customer analytics, and strategic recommendations into a single decision-support system.

Whether you're a business owner, analyst, manager, or executive, AI Business Copilot helps uncover hidden opportunities, anticipate risks, and improve business performance.

# ⚙️ Installation

## 1. Clone Repository

```bash
git clone https://github.com/leosanjit10/AI-Business-Copilot.git
cd AI-Business-Copilot
```

---

## 2. Create Virtual Environment

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### Mac/Linux

```bash
source venv/bin/activate
```

---

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4. Configure Environment Variables

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_api_key
```

---

## 5. Run Application

```bash
python -m streamlit run app.py
```
